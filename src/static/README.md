# `static`

В этой папке лежат все статические frontend-ресурсы проекта.

Содержимое:
- `css/` — стили интерфейса.
- `images/` — изображения и иконки.
- `js/` — точечные JavaScript-скрипты.

Как это работает:
- Django staticfiles собирает эти файлы в `STATIC_ROOT`.
- В production их раздаёт WhiteNoise после `collectstatic`.
- Файлы из этой папки не содержат серверной логики, но напрямую влияют на внешний вид и интерактивность UI.
