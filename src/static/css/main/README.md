# `css/main`

Эта папка разбивает основной UI на смысловые CSS-модули.

Содержимое:
- `foundation.css` — базовые переменные, reset и общие правила.
- `layout.css` — сетка и каркас страниц.
- `content.css` — оформление основного контента и карточек.
- `forms.css` — поля ввода, кнопки и формы.
- `alerts.css` — сообщения статусов и уведомления.
- `activity.css` — ленты событий и related UI-блоки.
- `responsive.css` — адаптация под разные размеры экрана.

Как это работает:
- Вместо одного монолитного файла стили разнесены по ответственности.
- Это упрощает изменение одной зоны интерфейса без побочных эффектов по всему UI.
- На странице итоговый стиль определяется порядком подключения этих файлов.
