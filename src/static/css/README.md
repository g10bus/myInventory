# `css`

Здесь лежат верхнеуровневые CSS-файлы страниц и разделов.

Содержимое:
- `login.css` — стили страницы входа.
- `register.css` — стили страницы регистрации.
- `style-main.css` — общий стиль основных внутренних страниц.
- `main/` — разложенные по зонам стили основного интерфейса.

Как это работает:
- Простые standalone-страницы используют отдельные файлы `login.css` и `register.css`.
- Основной внутренний интерфейс собирается из `style-main.css` и частных файлов в `main/`.
- Стили подключаются прямо из Django-шаблонов через тег `{% static %}`.
