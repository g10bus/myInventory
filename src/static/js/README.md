# `js`

Эта папка содержит клиентские скрипты интерфейса.

Содержимое:
- `searchable-select.js` — улучшение поведения выпадающих списков с поиском.

Как это работает:
- Скрипт подключается только там, где нужен интерактивный выбор значений.
- JavaScript здесь не формирует SPA, а лишь дополняет серверно-рендеренный Django-интерфейс.
