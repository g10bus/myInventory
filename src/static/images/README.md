# `images`

Эта папка содержит графические ассеты интерфейса.

Содержимое:
- Логотипы: `logo-box.png`, `logo1.png`.
- Иконки UI: `bell.png`, `bell-hover.png`, `log-out.png`, `box.png`, `Arrow 1.png`.
- Изображения профиля и декоративные материалы: `man-profile.png`, `women-profile.png`, `laptop.jpg`, `11.png`, `Group 447.png`.

Как это работает:
- Изображения подключаются из шаблонов и CSS через Django staticfiles.
- Здесь нет логики, но имена файлов и пути должны оставаться стабильными, иначе шаблоны начнут ссылаться на несуществующие ресурсы.
- При замене ассета лучше сохранять старое имя файла, если не хочется править шаблоны и стили.
