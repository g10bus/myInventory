# `apps`

Здесь размещены все доменные приложения проекта. Это основной слой modular monolith.

Содержимое:
- `accounts/` — пользователи, аутентификация, профиль и admin UI mode.
- `audit/` — журнал событий и единая точка логирования бизнес-операций.
- `core/` — инфраструктура, базовые модели, PDF и management-команды.
- `custody/` — выдача, возврат и передача ТМЦ между сотрудниками.
- `dashboard/` — главная панель и агрегированная аналитика.
- `integrations/` — 1С, Active Directory и их настройки.
- `inventory/` — карточки ТМЦ, сверки и назначения инвентаризации.
- `org/` — оргструктура, отделы и локации.

Как это работает:
- Каждая папка — отдельный Django app со своими моделями, формами, URL и вьюхами.
- Границы между apps держатся через `selectors.py`, `services.py`, формы и импорт моделей.
- В текущем проекте нет жёсткой изоляции по слоям, поэтому часть связей идёт напрямую между apps.
