# `inventory`

Это центральное приложение для работы с карточками ТМЦ и процессом инвентаризации.

Содержимое:
- `models.py` — `Asset`, фиксации инвентаризации и назначения периодов инвентаризации сотрудникам.
- `services.py` — создание и обновление карточек, запись сверки, отзыв назначений.
- `selectors.py` — выборки для личного списка ТМЦ, admin-экрана и истории инвентаризаций.
- `forms.py` — формы карточки ТМЦ и инвентаризационных действий.
- `ui.py` — presentation helper-ы для окна инвентаризации и истории фиксаций.
- `urls.py` — маршруты списка, карточки, admin-управления и назначений.
- `views/` — HTTP-обработчики инвентарного интерфейса.
- `tests.py` — тесты inventory UI logic.
- `migrations/` — миграции схемы inventory-моделей.
- `admin.py`, `apps.py`, `__init__.py` — регистрация app.

Как это работает:
- `Asset` — основная сущность ТМЦ, а `custody` использует её для фактического закрепления за сотрудником.
- Процесс инвентаризации строится на назначении периода сотруднику и записи `InventoryVerification`.
- В этом app разделены query-слой (`selectors.py`), mutation-слой (`services.py`) и UI helper-слой (`ui.py`).
