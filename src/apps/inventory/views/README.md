# `inventory/views`

Папка содержит web-вьюхи inventory-модуля.

Содержимое:
- `web.py` — личный список ТМЦ, карточка ТМЦ, admin-список, создание и редактирование карточек, назначения инвентаризации.
- `__init__.py` — технический файл пакета.

Как это работает:
- Пользовательские сценарии и admin-сценарии живут в одном модуле, но разделены guards доступа.
- Вьюхи стараются делегировать данные в `selectors.py`, изменения в `services.py`, а presentation helper-логику в `ui.py`.
- Это основной HTTP-вход в процессы инвентаризации и управления каталогом ТМЦ.
