# `inventory/migrations`

Папка хранит миграции схемы для ТМЦ и инвентаризационных сущностей.

Содержимое:
- `0001_initial.py` — создаёт базовую модель `Asset`.
- `0002_inventoryverification_and_images.py` — добавляет фиксации инвентаризации и изображения.
- `0003_employeeinventoryassignment.py` — добавляет назначения инвентаризации сотрудникам.
- `0004_employeeinventoryassignment_revocation.py` — добавляет отзыв назначений.
- `__init__.py` — технический файл пакета.

Как это работает:
- Эти миграции последовательно расширяют inventory-домен от простой карточки ТМЦ до полного процесса сверки.
- Файлы описывают историю изменений схемы и помогают понять эволюцию предметной модели.
