# `accounts/migrations`

Папка хранит миграции схемы для приложения пользователей.

Содержимое:
- `0001_initial.py` — создаёт базовую таблицу кастомного пользователя и связанные поля.
- `0002_user_avatar.py` — добавляет поддержку аватара.
- `__init__.py` — технический файл пакета миграций.

Как это работает:
- Django применяет миграции по порядку номеров.
- Эти файлы изменяют структуру БД, но не содержат runtime-логики.
- Новые изменения модели `User` должны сопровождаться новой миграцией, а не правкой старых файлов.
