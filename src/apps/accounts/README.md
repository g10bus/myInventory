# `accounts`

Приложение отвечает за пользователей, аутентификацию и персональные настройки интерфейса.

Содержимое:
- `models.py` — кастомная модель `User` с ФИО, ролью, отделом, локацией и аватаром.
- `forms.py` — формы входа, регистрации, профиля, смены пароля и пользовательского администрирования.
- `selectors.py` — выборки пользователей для UI и администрирования.
- `backends.py` — локальная email-аутентификация.
- `middleware.py` — принудительный logout неактивных пользователей.
- `context_processors.py` — пробрасывает режим интерфейса в шаблоны.
- `ui.py` — управление обычным и администраторским режимом интерфейса.
- `urls.py` — маршруты профиля, логина, регистрации и администрирования пользователей.
- `views/` — HTTP-обработчики.
- `migrations/` — эволюция схемы таблицы пользователей.
- `admin.py`, `apps.py` — регистрация app в Django.

Как это работает:
- Вход пользователя идёт через chain authentication backends: Active Directory и локальный email backend.
- После логина пользователь получает server-rendered UI, а его режим интерфейса определяется через `ui.py` и context processor.
- В админской части этого app реализовано управление профилями сотрудников, включая блокировку и редактирование кадровых полей.
