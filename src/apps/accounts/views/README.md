# `accounts/views`

Папка содержит web-вьюхи приложения `accounts`.

Содержимое:
- `web.py` — обработчики логина, регистрации, профиля, смены режима интерфейса и страниц управления пользователями.
- `__init__.py` — технический файл пакета.

Как это работает:
- View-функции получают запрос, валидируют формы и собирают context для шаблонов.
- Логика доступа к admin-экранам ограничивается декораторами и проверками ролей.
- Файл не хранит модели сам по себе, а координирует формы, selectors и сервисные helper-ы UI.
