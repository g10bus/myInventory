# `org`

Приложение отвечает за оргструктуру компании и справочники локаций.

Содержимое:
- `models.py` — модели отделов и локаций.
- `forms.py` — формы создания отделов и локаций.
- `urls.py` — маршруты административного экрана оргструктуры.
- `views/` — web-вьюхи оргсправочников.
- `migrations/` — история изменений схемы.
- `admin.py`, `apps.py`, `__init__.py` — регистрация app.

Как это работает:
- Другие apps, прежде всего `accounts` и `integrations`, используют `Department` и связанные справочники.
- UI здесь довольно простой: администратор заводит и поддерживает организационные сущности через формы.
