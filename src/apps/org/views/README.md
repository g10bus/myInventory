# `org/views`

Папка хранит web-вьюхи для управления оргструктурой.

Содержимое:
- `web.py` — административный экран создания отделов и локаций.
- `__init__.py` — технический файл пакета.

Как это работает:
- View-файл простой: готовит две формы, различает POST-действия и рендерит справочники.
- Это небольшой CRUD-узел, который обслуживает остальные доменные модули через справочные данные.
