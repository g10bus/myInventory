# `org/migrations`

Папка хранит миграции схемы оргструктуры.

Содержимое:
- `0001_initial.py` — создаёт базовую модель отдела.
- `0002_location.py` — добавляет модель локации или расширяет работу со справочником локаций.
- `__init__.py` — технический файл пакета.

Как это работает:
- Эти файлы задают справочники, от которых зависят профили пользователей и импорт данных из 1С.
- Порядок применения миграций определяет эволюцию модели оргструктуры.
