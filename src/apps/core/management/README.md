# `core/management`

Папка для management-инфраструктуры Django внутри `core`.

Содержимое:
- `commands/` — кастомные команды, доступные через `python manage.py ...`.
- `__init__.py` — технический файл пакета.

Как это работает:
- Django автоматически ищет management-команды по этому пути.
- Всё, что находится в `commands/`, становится CLI-интерфейсом для служебных операций проекта.
