# `core/management/commands`

Здесь лежат кастомные CLI-команды приложения `core`.

Содержимое:
- `bootstrap_roles.py` — создаёт системные группы и роли, на которые опирается доступ в интерфейсе.
- `__init__.py` — технический файл пакета.

Как это работает:
- Команда вызывается как `python manage.py bootstrap_roles`.
- Обычно её запускают после миграций на новой среде или в CI.
- Она подготавливает RBAC-слой, чтобы проверки `is_administrator` имели ожидаемую опору в группах.
