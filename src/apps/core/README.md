# `core`

Это инфраструктурное приложение с общими строительными блоками проекта.

Содержимое:
- `models.py` — базовая абстрактная модель `TimeStampedModel`.
- `access.py` — общие guard-ы доступа: admin-проверка и POST-only декоратор.
- `views.py` — инфраструктурные web-endpoint-ы, если они нужны приложению.
- `pdf.py` — общие helper-ы для генерации PDF-ответов.
- `tests.py` — сквозные web-тесты и проверки инфраструктурных helper-ов.
- `management/` — management-команды Django.
- `apps.py`, `__init__.py` — регистрация app.

Как это работает:
- `core` не описывает отдельную предметную область, а обслуживает остальные apps.
- Общие декораторы и базовые модели убирают дублирование между модулями.
- В этом app удобно держать cross-cutting logic, которая не принадлежит одному домену.
