# `audit`

Приложение реализует журнал бизнес-событий системы.

Содержимое:
- `models.py` — модель `AuditEvent` с типом события, актором, связанным пользователем, ТМЦ и metadata.
- `services.py` — сервис записи событий в журнал.
- `admin.py` — регистрация модели журнала в Django admin.
- `migrations/` — миграции структуры audit-таблиц.
- `apps.py`, `__init__.py` — техническая регистрация app.

Как это работает:
- Другие apps вызывают audit service при значимых операциях: выдаче, возврате, передаче, инвентаризации, синхронизации.
- Запись в журнал централизует историю изменений и упрощает отчёты.
- `metadata` в модели позволяет хранить дополнительные поля без немедленного усложнения схемы БД.
