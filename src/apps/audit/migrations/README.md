# `audit/migrations`

Папка хранит миграции схемы журнала событий.

Содержимое:
- `0001_initial.py` — создаёт таблицу `AuditEvent`.
- `__init__.py` — технический файл пакета.

Как это работает:
- При первом разворачивании проекта эта миграция поднимает основу для журналирования.
- Дальнейшие изменения в структуре аудита должны добавляться новыми миграциями поверх неё.
