# `custody/views`

Папка хранит HTTP-обработчики сценариев закрепления и передачи ТМЦ.

Содержимое:
- `web.py` — пользовательская история, обмен, PDF-отчёты и административное управление выдачей/возвратом/передачей.
- `__init__.py` — технический файл пакета.

Как это работает:
- View-функции получают действие из POST (`action`) и маршрутизируют его в нужный сервисный сценарий.
- При ошибках доменного слоя ловится `CustodyError`, а результат отдаётся через Django messages.
- Для сложных операций данные собираются заранее через selectors и передаются в шаблон единым context.
