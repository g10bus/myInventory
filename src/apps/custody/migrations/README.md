# `custody/migrations`

Папка содержит миграции схемы для выдачи, возврата и передачи ТМЦ.

Содержимое:
- `0001_initial.py` — создаёт таблицы закреплений и заявок на передачу.
- `__init__.py` — технический файл пакета.

Как это работает:
- Миграция поднимает структуру, на которой строится модуль `custody`.
- Изменения полей `AssetAssignment` и `TransferRequest` должны идти новыми миграциями.
