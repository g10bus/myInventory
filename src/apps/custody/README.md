# `custody`

Приложение управляет жизненным циклом закрепления ТМЦ за сотрудниками.

Содержимое:
- `models.py` — модели выдачи и передачи, включая текущее закрепление и заявки на transfer.
- `services.py` — бизнес-операции выдачи, возврата, создания, подтверждения и отклонения передач.
- `selectors.py` — выборки для истории, экранов передачи и admin-контекста.
- `forms.py` — формы выдачи, возврата и передачи.
- `reports.py` — генерация PDF-отчётов по передаче и истории.
- `tests.py` — тесты сервисного слоя закрепления.
- `urls.py` — маршруты истории, обмена и админского экрана.
- `views/` — web-вьюхи.
- `migrations/` — миграции схемы закрепления.
- `admin.py`, `apps.py` — регистрация app.

Как это работает:
- `services.py` — центр доменной логики: там переключается `is_current`, обновляется статус ТМЦ и пишется аудит.
- View-слой в основном валидирует формы и вызывает эти сервисы.
- Это приложение тесно связано с `inventory` через модель `Asset` и с `audit` через запись событий.
