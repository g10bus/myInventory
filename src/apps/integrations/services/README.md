# `integrations/services`

Папка содержит сервисный слой для работы с внешними системами.

Содержимое:
- `one_c.py` — клиент и orchestration синхронизации данных из 1С.
- `active_directory.py` — подключение к LDAP/Active Directory, проверка связи и загрузка профиля.
- `logging.py` — журналирование результатов интеграций.
- `__init__.py` — технический файл пакета.

Как это работает:
- `one_c.py` получает удалённые сущности и преобразует их в локальные модели `Department`, `User`, `Asset`.
- `active_directory.py` нужен и для проверки соединения, и для логина через backend.
- `logging.py` отделяет технический лог обмена от общего бизнес-аудита.
