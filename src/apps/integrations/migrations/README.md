# `integrations/migrations`

Папка содержит миграции схемы для настроек интеграций и логов синхронизаций.

Содержимое:
- `0001_initial.py` — создаёт таблицы настроек 1С, Active Directory и журналов обмена.
- `__init__.py` — технический файл пакета.

Как это работает:
- На эту схему опираются как web-настройки интеграций, так и management-команды.
- Изменения контрактов хранения должны оформляться отдельными миграциями.
