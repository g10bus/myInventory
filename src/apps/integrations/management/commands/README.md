# `integrations/management/commands`

Здесь находятся команды Django для запуска интеграций из консоли.

Содержимое:
- `sync_one_c_data.py` — ручной запуск синхронизации данных из 1С.
- `test_active_directory_connection.py` — проверка LDAP/AD-подключения.
- `__init__.py` — технический файл пакета.

Как это работает:
- Команды вызывают тот же сервисный слой, что и web-интерфейс.
- Это позволяет держать единую доменную логику и не дублировать код между UI и CLI.
