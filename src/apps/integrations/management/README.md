# `integrations/management`

Папка для CLI-инфраструктуры приложения интеграций.

Содержимое:
- `commands/` — management-команды для внешних систем.
- `__init__.py` — технический файл пакета.

Как это работает:
- Команды используются для ручного запуска интеграций без захода в web-интерфейс.
- Это удобно для cron, разовых операций и диагностики среды.
