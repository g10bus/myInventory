# `integrations`

Приложение отвечает за внешние интеграции проекта.

Содержимое:
- `models.py` — настройки интеграций и журналы синхронизаций.
- `forms.py` — формы редактирования настроек 1С и Active Directory.
- `services/` — клиенты и orchestration для 1С, AD и логирования синхронизаций.
- `backends.py` — authentication backend для Active Directory.
- `urls.py` — маршруты административного интерфейса интеграций.
- `views/` — web-экран управления интеграциями.
- `management/` — CLI-команды ручного запуска и проверки подключений.
- `tests.py` — тесты интеграционных сценариев с моками.
- `migrations/` — миграции схемы настроек и логов.
- `admin.py`, `apps.py`, `__init__.py` — регистрация app.

Как это работает:
- Настройки подключений хранятся в базе, а не только в `.env`.
- 1С отвечает за импорт отделов, сотрудников и ТМЦ.
- Active Directory используется для доменной аутентификации и, при необходимости, синхронизации профиля при входе.
