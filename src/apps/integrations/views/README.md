# `integrations/views`

Папка хранит web-вьюхи управления интеграциями.

Содержимое:
- `web.py` — административная страница настройки 1С и Active Directory, ручной sync и test connection.
- `__init__.py` — технический файл пакета.

Как это работает:
- Вьюха инициализирует singleton-like записи настроек и рендерит единый экран управления.
- POST-действия выбираются через поле `action`, после чего вызываются сервисы интеграций.
- Результат сообщается через Django messages и журналы синхронизаций.
