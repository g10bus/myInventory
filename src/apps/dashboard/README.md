# `dashboard`

Приложение собирает главную страницу системы и администраторскую аналитику.

Содержимое:
- `selectors.py` — агрегирующие выборки для dashboard и analytics.
- `urls.py` — корневые маршруты home и analytics.
- `views/` — HTTP-обработчики этих страниц.
- `apps.py`, `__init__.py` — регистрация app.

Как это работает:
- Здесь почти нет собственных моделей, потому что app в основном агрегирует данные из других доменов.
- `selectors.py` превращает разрозненные сущности в готовые виджеты и summary-данные для интерфейса.
- Обычный пользователь видит dashboard, а аналитика ограничена администраторским доступом.
