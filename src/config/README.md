# `config`

Эта папка содержит каркас Django-проекта как приложения: settings, ASGI/WSGI и корневые URL.

Содержимое:
- `__init__.py` — делает папку Python-пакетом.
- `asgi.py` — точка входа для ASGI-сервера.
- `wsgi.py` — точка входа для WSGI-сервера.
- `urls.py` — корневой роутинг проекта.
- `settings/` — набор настроек для разных окружений.

Как это работает:
- При старте Django загружает settings-модуль и роутинг отсюда.
- `urls.py` собирает URL из доменных apps в единое дерево маршрутов.
- `asgi.py` и `wsgi.py` нужны не для бизнес-логики, а для интеграции с сервером приложений.
