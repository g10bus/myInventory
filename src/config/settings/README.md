# `settings`

Эта папка хранит раздельные настройки Django для разных режимов запуска.

Содержимое:
- `base.py` — базовая конфигурация проекта: apps, middleware, static/media, auth, logging.
- `local.py` — локальные настройки разработки.
- `prod.py` — production-режим.
- `test.py` — тестовая конфигурация для CI и локальных тестов.
- `__init__.py` — технический файл пакета.

Как это работает:
- Обычно конкретный settings-модуль выбирается через `DJANGO_SETTINGS_MODULE`.
- `base.py` задаёт общий каркас, а `local.py`, `prod.py`, `test.py` только уточняют различия среды.
- Значительная часть конфигурации читается из `.env` через `django-environ`.
