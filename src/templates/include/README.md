# `templates/include`

Папка для повторно используемых кусочков шаблонов.

Содержимое:
- `navbar.html` — верхняя навигация и элементы общего интерфейса.

Как это работает:
- Include-шаблоны вставляются в другие HTML-файлы через `{% include %}`.
- Это уменьшает дублирование общей разметки и делает навигацию централизованной.
