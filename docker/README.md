# `docker`

Эта папка содержит runtime-файлы для запуска приложения в контейнере.

Содержимое:
- `entrypoint.sh` — стартовый shell-скрипт контейнера.
- `gunicorn.conf.py` — конфигурация Gunicorn для production HTTP-сервера.

Как это работает:
- `entrypoint.sh` создаёт рабочие каталоги `var/static` и `var/media`.
- Если задан `DATABASE_URL`, скрипт ждёт готовности базы через `psycopg`.
- По флагам окружения может автоматически запускать `collectstatic` и `migrate`.
- После подготовки управление передаётся финальной команде контейнера, обычно Gunicorn.
