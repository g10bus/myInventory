# `docs`

Эта папка хранит актуальную техническую документацию проекта.

Содержимое:
- `database_architecture.md` — схема и логика предметной модели БД.

Как это работает:
- Файлы здесь не участвуют в runtime приложения.
- Здесь стоит хранить только документацию, которая помогает разработке и сопровождению.
- Если документ перестал соответствовать коду или описывает учебный/декоративный контекст, его лучше удалить или переписать.
