# `scripts`

Эта папка содержит вспомогательные shell-скрипты для обслуживания базы данных.

Содержимое:
- `backup_db.sh` — создаёт SQL-дамп базы в `var/backups`.
- `restore_db.sh` — восстанавливает базу из указанного SQL-файла.

Как это работает:
- Оба скрипта используют `DATABASE_URL`.
- `backup_db.sh` вызывает `pg_dump` и складывает файл с timestamp в имени.
- `restore_db.sh` передаёт файл в `psql`.
- Скрипты не управляют миграциями и не валидируют структуру данных, они работают на уровне raw SQL dump/restore.
