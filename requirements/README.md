# `requirements`

Здесь хранятся списки Python-зависимостей для разных сценариев сборки.

Содержимое:
- `base.in` — человекочитаемый исходный набор базовых зависимостей.
- `base.txt` — зафиксированный результат для базового набора.
- `prod.in` — production-надстройка над базовыми пакетами.
- `prod.txt` — итоговый production lock-файл, который используется в CI и контейнере.

Как это работает:
- `.in` файлы задают намерение: какие библиотеки проекту нужны.
- `.txt` файлы используются для воспроизводимой установки одинаковых версий.
- При обновлении стеков сначала меняют `.in`, затем пересобирают `.txt`.
